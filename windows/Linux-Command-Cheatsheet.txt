[[Essential Commands & Quick Reference]]
----------------------------------------

[[Task]]                              [[Command]]           [[Description]]
  Switch to root (Non-login shell)      su                    Switches to the root user but retains your current user's environment (variables, PATH, directory).
  Switch to root (Login shell)          su - (or su --login)  Recommended. Switches to root and loads a fresh login shell, inheriting root's environmental variables, PATH, and home directory (/root).
  Switch to another user                su <username>         Switches to the specified user account using your current environment variables.
  Switch to another user (Login shell)  su - <username>       Switches to the specified user with their complete login environment.
  Run a single command                  su -c '<command>'     Executes a single command as the target user without opening a full interactive shell.
  Exit the user session                 exit (or Ctrl+D)      Closes the current subshell and returns you to your previous user session.

[[Command]]                       [['su' Description]]
  su                                Switch to root
  su -                              Switch to root (login shell)
  su <username>                     Switch to another user
  su -c 'command'                   Run a command as root
  su -s /bin/zsh                    Use a specific shell
  su -p                             Preserve environment
  sudo su -                         Switch to root via sudo
  sudo su - <username>              Switch to another user via sudo
  sudo -i                           Sudo login shell

[[Command]]                       [['sudo' Description]]
  sudo 'command'                    Run a command as root
  sudo -u <user> 'command'          Run a command as a specific user
  sudo -i                           Open a root login shell
  sudo -s                           Open a root shell (non-login)
  sudo -l                           List sudo privileges for the current user
  sudo -l -U <user>                 List sudo privileges for another user
  sudo -v                           Refresh cached credentials without running a command
  sudo -k                           Invalidate cached credentials for the current terminal
  sudo -K                           Remove cached credentials for every terminal
  sudo -n 'command'                 Fail with an error instead of prompting for a password
  sudo -E 'command'                 Preserve your current environment variables
  sudo -b 'command'                 Run the command in the background
  sudo -H 'command'                 Set 'HOME' to the target user’s home directory
  sudo -D <dir> 'command'           Run in a specific directory when sudoers permits '-D'
  sudo sh -c '...'                  Run a full command line, pipes and redirects included, as root
  sudo -e <filename>                Edit a file as root using your default editor
  sudo visudo                       Edit the sudoers file safely
